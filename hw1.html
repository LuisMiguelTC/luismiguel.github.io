1. Introduction & Theoretical Foundations

Elliptic-curve scalar multiplication serves as a cornerstone of modern asymmetric cryptography, acting as a cryptographic one-way function. In the forward direction, given a private key $k$ (a scalar integer) and a base generator point $G$, computing the public key $Q = kG$ is efficient and deterministic. Conversely, recovering $k$ from $Q$ relies on the hardness of the Elliptic Curve Discrete Logarithm Problem (ECDLP).

While sharing similarities with cryptographic hash functions (such as one-wayness), ECC is grounded in algebraic geometry over finite fields rather than bitwise mixing operations.

2. Toy Scheme Specification & Parameters

To understand the core mechanisms without the complexity of 256-bit numbers, we implement a simplified toy model:

  • Finite Field Prime ($p$): $17$
  • Elliptic Curve Equation: $y^2 \equiv x^3 + 7 \pmod{17}$
  • Base Generator Point ($G$): $(1, 5)$
  • Private Key ($k$): $6$

The objective is to compute successive point additions ($G, 2G, 3G, \dots, kG$) to derive the final public key point $Q = 6G$.

3. Python Implementation of Point Operations

Below is a Python implementation showing how point addition, point doubling, and scalar multiplication operate under modular arithmetic for the toy curve:

def point_add(P, Q, p=17, a=0):
    """Computes R = P + Q on y^2 = x^3 + a*x + b (mod p)"""
    if P is None: return Q
    if Q is None: return P
    
    x1, y1 = P
    x2, y2 = Q
    
    if x1 == x2 and y1 != y2:
        return None # Point at infinity
        
    if P == Q:
        if y1 == 0: return None
        # Point Doubling formula: lambda = (3*x1^2 + a) * (2*y1)^(-1) mod p
        lam = (3 * x1 * x1 + a) * pow(2 * y1, p - 2, p) % p
    else:
        # Point Addition formula: lambda = (y2 - y1) * (x2 - x1)^(-1) mod p
        dx = (x2 - x1) % p
        dy = (y2 - y1) % p
        lam = dy * pow(dx, p - 2, p) % p
        
    x3 = (lam * lam - x1 - x2) % p
    y3 = (lam * (x1 - x3) - y1) % p
    return (x3, y3)

def scalar_mult(k, G, p=17, a=0):
    """Computes Q = k * G using double-and-add algorithm"""
    R = None
    curr = G
    while k > 0:
        if k & 1:
            R = point_add(R, curr, p, a)
        curr = point_add(curr, curr, p, a)
        k >>= 1
    return R

# Parameters test
G = (1, 5)
k = 6
Q = scalar_mult(k, G)
print(f"Toy Public Key (6G): {Q}")

4. Statistical Exploration & Discussion

By executing scalar multiplication across various values of $k$ and exploring the resulting points on the curve, we evaluate several statistical dimensions:

Statistical Property Observation on Toy ECC Comparison with Hash Functions
Coordinate Distribution Points are strictly bound to valid curve coordinates over $\mathbb{F}_{17}$. Hash functions produce uniformly distributed pseudo-random bitstrings across the output space.
Avalanche Effect Slight changes in scalar $k$ result in geometric group transitions rather than random bit flips. Strict avalanche criterion is mandatory: a 1-bit change in input alters ~50% of output bits.
Input-Output Correlation Strong structural correlation due to underlying algebraic group laws. Zero correlation (unpredictable output independent of input).

Conclusion: Properties like the avalanche effect and bit-level pseudo-randomness are specific to cryptographic hash functions (like Keccak or SHA-2), whereas ECC properties are fundamentally governed by algebraic structure, discrete logarithms, and geometric point cycles.
