Homework 1: Public-Key Cryptography (Private Key to Public Key in Ethereum)

Course: Statistics for Cybersecurity | La Sapienza University of Rome

1. Objective & Background

Elliptic-curve scalar multiplication can be viewed as a cryptographic one-way function. It is deterministic and easy to compute in the forward direction ($k \to Q = kG$), while recovering $k$ from $Q$ is computationally difficult based on the Elliptic Curve Discrete Logarithm Problem (ECDLP).

The goal is to understand the basic mechanics of elliptic-curve scalar multiplication using a toy model rather than implementing a full cryptographic system.

2. Toy Scheme Implementation

For this experiment, we use the following parameters:

  • Toy Curve: $$y^2 \equiv x^3 + 7 \pmod{17}$$
  • Base Point ($G$): $(1, 5)$
  • Private Key ($k$): $6$

The public key is computed as $Q = kG$ by implementing basic point-addition operations to generate $G, 2G, 3G, \dots, kG$.

3. Statistical Exploration

By repeating the experiment with different values of $k$ and valid base points, we analyze simple statistical properties:

  • Distribution of coordinates: Examining the dispersion of $x$ and $y$ coordinates across the finite field.
  • Frequency & Uniformity: Checking individual value occurrences and apparent uniformity.
  • Correlations & Avalanche behavior: Evaluating relationships between inputs and outputs.

Discussion: While cryptographic hash functions aim for strict avalanche effects and uniform bit-diffusion, algebraic structures like ECC preserve strict geometric group properties, meaning certain correlations stem directly from the underlying mathematical curve equation.
